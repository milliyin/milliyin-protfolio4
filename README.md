# Milliyin Template

A simplified Astro portfolio template based on the structure of the cloned reference project, trimmed down so you can customize it quickly.

## What was removed

- Blogs
- Certificates
- Analytics
- Open Graph image generator
- Most of the original content volume

## Main files to edit

- `src/site.ts`
- `src/content/projects/*.md`
- `src/content/skills/*.md`
- `src/content/experience/*.md`
- `src/components/ImageGrid.astro`

## Commands

| Command | Action |
| :-- | :-- |
| `pnpm install` | Install dependencies |
| `pnpm dev` | Start local development server |
| `pnpm build` | Build to `dist/` |
| `pnpm preview` | Preview the production build |

## Notes

This template lives in `milliyin-template/` so the original reference clone stays available separately in `reference-anav-dev/`.
